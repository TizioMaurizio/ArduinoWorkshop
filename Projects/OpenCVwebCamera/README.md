# OpenCVwebCamera

OpenCV webcam playground:

- `realtime_shape_detection.py` — contour-based shape classifier
- `AnimeColor.py` / `AnimeColor2.py` — webcam-driven color extractor
- `AnimeColorBlaster.ino` — Arduino IR blaster that fires color codes on serial commands
- `Functions.py` / `NumberMapper.py` / `SerialTester.py` — shared helpers
