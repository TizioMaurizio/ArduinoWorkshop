# RobotArmRevised

Glove-driven biped/arm controller with multiple Tk-based GUIs:

- `Biped_GUANTO.py` — sensor-glove → servo angle streamer
- `Biped_GUI_V1.py` / `Biped_GUI_V1_interp.py` — manual gait editors with interpolation
- `GloveFit.py` — glove calibration helper
- `PlotGait.py` + `narrowGaitV2_interp.json` — saved gaits and visualization
